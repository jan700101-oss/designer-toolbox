# 設計師的工具箱

手機隨行的案場工具，無需第三方 API 金鑰。

## 使用與安裝

開啟 GitHub Pages 網站，允許定位，或手動填寫案場地址。選擇五金材料、住宿、餐飲，再開啟 Google 地圖搜尋與導航。分項搜尋可減少因分類過窄而漏找。

- iPhone：Safari → 分享 → 加入主畫面。
- Android：Chrome → 選單 → 安裝應用程式／加到主畫面。
- 手機系統與瀏覽器均需允許定位；如有精確位置選項，請開啟。

## 定位與資料限制

定位會比較最多三次新的高精度讀值，選擇裝置回報誤差最小者。估計誤差超過100公尺時不採用，仍需人工確認案場入口。回報精度不是實際位置正確的保證。

附近商家在 Google 地圖顯示，不會抓取 Google 商家資料。收錄、排名、搜尋範圍與營業資訊由 Google 決定，無法保證收錄所有店家。URL 中的 api=1 是地圖連結格式，不需要金鑰。

自訂店家儲存在目前瀏覽器的 localStorage，不會上傳到 GitHub。不同網址／手機的店家資料不會自動同步。公開程式庫不包含使用者的定位或店家資料。

離線可在首次成功載入後重新開啟並查看自訂店家；地圖搜尋與導航仍需網路。外部字型與圖示離線時可能無法載入。

## 部署與修改

純靜態 HTML、JavaScript、manifest 與 Service Worker。GitHub Pages 發布 main 分支根目錄，HTTPS。manifest 使用相對起始路徑與 scope，支援專案子目錄。

本機預覽：`python -m http.server 8765`，瀏覽器開啟 `http://localhost:8765/`。更新時修改 Service Worker 快取版本。
